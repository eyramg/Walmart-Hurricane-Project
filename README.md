# Walmart Hurricane Analytics Project

**Course:** DS2002 – Data Science Systems  
**University:** University of Virginia  
**Semester:** Fall 2026

## Project Overview

This midterm group project examines Walmart sales patterns before hurricanes in Florida. Our team will clean and analyze transaction data, integrate historical weather information, and investigate changes in consumer purchasing behavior.

The goal is to provide data-driven recommendations to help Walmart prepare its inventory and distribution operations before severe weather events.

## Project Objectives

1. Clean and standardize Walmart transaction data.
2. Consolidate inconsistent product names and SKU codes.
3. Retrieve and integrate historical weather data using an API.
4. Identify product categories with increased demand before hurricanes.
5. Analyze geographic differences in purchasing behavior.
6. Investigate whether increased board game sales represent genuine demand or data errors.
7. Provide evidence-based business recommendations.

## Running the Project

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `notebooks/team_notebook.ipynb`.
4. Ensure the notebook can access the files in `data/`.
5. Run the notebook cells in order.

The main notebook is currently under development. The team will verify that it runs successfully from start to finish before final submission.
